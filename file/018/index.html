コスタリカの石球——密林の、完璧な球

第1部｜発見

一九三〇年代のこと。中央アメリカ、コスタリカの、南部。ディキスと呼ばれる、川沿いの、深いジャングルでのことだった。アメリカの、あるバナナ会社が、農園を広げるため、密林を、切り開いていた。労働者たちが、生い茂る木々を、なぎ倒し、土を、掘り返していく。その時、彼らの道具が、土の中の、何か固いものに、当たった。

石の、球土の中から、次々と現れた
記録 01 最初の発見

土を払うと、そこから現れたのは、まん丸い、石の球だった。人の手で、磨いたとしか思えない、なめらかな、球体。一つではない。掘れば掘るほど、同じような球が、あちこちから、出てきた。

記録 02 大きさ

大きさは、さまざまだった。手のひらに乗る、小さなものから、人の背丈を超え、直径二メートル、重さ十六トンにもなる、巨大なものまで。そのどれもが、不思議なほど、正確な球の形をしていた。

やがて、その数は、数百にものぼった。誰が、これを作ったのか。何のために。労働者たちには、見当も、つかなかった。ジャングルの、静けさの中に、無数の完璧な球だけが、ただ、転がっていた。

第2部｜謎

そして、答えは、破壊された

この、奇妙な球の噂は、すぐに、広まった。そして、ある、よくない噂も、一緒に広まってしまう。——あの石の球の、中には、黄金や、宝石が、詰まっているに違いない。そう、人々は、考えたのだ。

宝を求めて、人々は、球を、割り始めた。ドリルで、穴をあけ、ダイナマイトで、爆破する。もちろん、中から、宝など、出てはこない。ただの、石だ。こうして、数えきれないほどの球が、粉々に、砕かれた。取り返しの、つかない、破壊だった。

この破壊が、最大の悲劇を、生んだ。石球は、もともと、ある決まった場所に、ある決まった並びで、置かれていたらしい。その「並び」にこそ、作った人々の、意図が、隠されていた。だが、宝探しのために、球は、動かされ、砕かれ、バラバラにされてしまった。——石球が、なぜ、そこにあったのか。その答えは、こうして、永遠に、失われたのである。

第3部｜「人間業ではない」

広がる、超常の噂

並びという、手がかりを失った石球は、いよいよ、謎めいた存在になっていく。とりわけ、人々を、驚かせたのは、その「完璧さ」だった。これほど、正確な球を、どうやって、作ったのか。近代的な、機械もない、大昔の人々に、そんなことが、できるはずがない。

やがて、こんな声まで、聞こえ始める。——これは、宇宙人が、作ったのだ。あるいは、海に沈んだ、伝説の超古代文明の、遺産だ。人間の技術では、絶対に、作れない。だから、これは、オーパーツ。その時代に、あるはずのない、場違いな、遺物なのだ、と。

本当に、人間には、
作れないものなのだろうか。

当調査局の結論。コスタリカの石球は、宇宙人でも、超古代文明でも、ありません。実在した、ディキスという先住民が、石の道具だけで、途方もない手間をかけて、作り上げたものです。「人間には作れない」というのは、誤りです。むしろ、人間だからこそ、作れた。そう言うべきでしょう。
